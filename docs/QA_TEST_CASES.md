# iReside System QA Test Cases

This document contains end-to-end quality assurance (QA) test cases for the iReside Property Management System, organized by **User Role** (**Landlord**, **Tenant**, and **System Security & Accessibility**). Within each role, test cases follow a **natural, chronological workflow order** so validators can test an entire user journey from login to sign-out without switching contexts back and forth.
