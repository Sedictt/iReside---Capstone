Getting Started Requirements & Sign In

Prerequisites Before Getting Started

Ensure you have the following items ready before accessing iReside:

  • Smartphone or Computer: Any modern Android phone, iPhone, or laptop.
  • Internet Connectivity: Active Wi-Fi or mobile cellular data connection.
  • Valid Email Address: Used for login verification and digital receipts.
  • Account Credentials: Email and temporary password provided by management.

How to Sign In to Your Account

Follow these standard steps to authenticate into the system:

  1. Open your browser and navigate to the official iReside portal.
  2. Enter your registered email address in the Email Address field.
  3. Enter your password in the Password field.
  4. Click the Sign In button.
  5. Retrieve the 6-digit verification code sent to your email inbox.
  6. Type the code into 6-Digit Verification Code and click Verify & Sign In.

Sign-In Credentials & Verification Matrix

Credential Field Input Format Verification Rule
Email Address Standard valid email string Must match active profile record.
Account Password Minimum 8 alphanumeric characters Case-sensitive credentials.
Verification Code 6-digit numeric OTP code One-time code expiring in 10 minutes.
Authentication Step User Action System Response
1. Submit Details Enter email and temporary password. System validates registered account.
2. Receive Code Retrieve 6-digit email passcode. Code remains valid for ten minutes.
3. Authorize Type code into verification prompt. Redirects to role dashboard immediately.
Login Standard: Two-factor verification protects accounts against unauthorized access.
Warning: Never share your password or verification code with anyone. Keep it confidential.

Getting Started App Setup & Spare Key

How to Install the Mobile App

You can install iReside on your mobile phone for fast daily access:

Android Installing on Android Phone
  1. Open the left sidebar menu and click Download App.
  2. Click Download iReside App to save the APK file.
  3. Open your downloaded file and click Install.
  4. When prompted by Android security, tap Allow to continue.
iPhone Adding to iPhone Home Screen
  1. Open the Safari browser and navigate to the iReside portal.
  2. Tap the Share button at the bottom of the screen.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the top-right corner to complete setup.

Support & Security Troubleshooting Guide

Troubleshooting Frequently Encountered Issues

1. Did not receive 2FA verification email?

Check your Spam or Junk folder. Wait 60 seconds before clicking Resend Code.

2. Forgotten password and unable to access email?

Use your Emergency Spare Key. Click Use Emergency Key on the login screen.

3. Weak internet connection while submitting payments?

Save your receipt screenshot. Upload proof once your internet connection is restored.

4. Submitted payment not yet deducted from balance?

Landlords must review and confirm receipts before balances update on screen.

5. How to upload clear repair request photos?

Turn on room lighting. Capture close-up photos of the specific damaged fixtures.

6. Who to contact during building emergencies?

Contact management emergency hotlines or Barangay Marulas Rescue Services immediately.

7. How to resolve camera permission errors when uploading receipts?

Open phone browser settings. Tap Site Settings, select Camera, and choose Allow.

Essential Security Guidelines

  • Keep Passwords Secret: Never share passwords with anyone. Use mixed letters and numbers.
  • Store Emergency Keys Safely: Save your spare key on a flash drive or notebook.
  • Beware of Phishing Messages: Never log in through text message links. Use official URLs.
  • Archive Payment Receipts: Save reference numbers and keep digital payment proof files.
  • Protect Personal Identity Data: Government IDs remain encrypted and restricted to verified management.

Access Control Strict Two-Role Human User Model

Strict Two-Role Human User Model

Per system rules, iReside implements a strict two-role model with zero admin role:

  • Landlord: Property owner. Manages properties, unit maps, leases, invoices, and maintenance.
  • Tenant: Resident occupant. Signs digital leases, submits payments, logs maintenance tickets.

Service Role Operational Model

Automated processes that require cross-tenant or system-level access use secure service role tokens:

  • Automated Billing Cron: Daily midnight worker generates recurring rent and overdue charges.
  • Workspace Initialization (/api/setup/launch): Bypasses client RLS to stamp initial configuration.
  • Disaster Recovery & Seeding: Dedicated CLI maintenance scripts run via service role key.

Authentication 2FA Engine & Session Guards

Two-Factor Authentication (2FA) Lifecycle

iReside implements mandatory email-delivered 6-digit OTP verification for secure sessions:

  1. User submits credentials at /login via Supabase Auth PKCE flow.
  2. Server generates an ephemeral 6-digit cryptographic token (10-minute expiry).
  3. Token is dispatched via transactional SMTP to the verified email.
  4. User inputs token; upon verification, Supabase issues signed JWT and refresh tokens.

Authentication Threat Model & Defense Mechanisms

Threat Vector Risk Level Defense Architecture
Brute Force Login High Rate limit: 5 failed attempts per IP.
Session Hijacking Critical HTTP-only SameSite cookies and TLS 1.3.
OTP Replay Attack Medium 10-minute expiry on single-use OTP codes.
Client Lock Stalls High Background non-blocking auth refresh execution.
