Unang Hakbang Mga Kinakailangan at Pag-sign In

Mga Kailangan Bago Magsimula

Ihanda ang mga sumusunod bago buksan ang iReside portal:

  • Smartphone o Kompyuter: Anumang Android phone, iPhone, o laptop.
  • Koneksyon sa Internet: Aktibong Wi-Fi o mobile data load.
  • Aktibong Email Address: Para sa verification code at resibo.
  • Mga Kredensyal: Email at password mula sa pamunuan.

Paano Mag-sign In sa Iyong Account

Sundin ang mga hakbang na ito upang makapasok sa portal:

  1. Buksan ang browser at pumunta sa opisyal na iReside website.
  2. I-type ang rehistradong email sa Email Address field.
  3. I-type ang iyong password sa Password field.
  4. Pindutin ang Sign In button sa ibaba.
  5. Tingnan ang 6-digit verification code na ipinadala sa iyong email.
  6. I-type ang code sa 6-Digit Verification Code at i-click ang Verify & Sign In.

Talahanayan ng Kredensyal at Pagpapatunay

Field ng Kredensyal Uri ng Input Tuntunin sa Pagsusuri
Email Address Karaniwang wastong email Dapat tugma sa profile record.
Password ng Account Hindi bababa sa 8 karakter Case-sensitive na mga titik at numero.
Verification Code 6-digit numeric OTP code Mawawalan ng bisa makalipas ang 10 minuto.
Hakbang sa Pag-login Aksyon ng Gumagamit Tugon ng Sistema
1. Ilagay ang Detalye I-type ang email at pansamantalang password. Titingnan ng sistema ang rehistradong account.
2. Kunin ang Code Kunin ang 6-digit passcode sa email. Bisa ang code sa loob ng sampung minuto.
3. Pagpapatunay I-type ang code sa verification prompt. Dadalhin ka agad sa dashboard ng iyong role.
Pamantayan sa Pag-login: Pinoprotektahan ng 2FA ang mga account laban sa hindi awtorisadong pag-access.
Babala: Huwag ibigay ang iyong password o verification code kaninoman. Panatilihing lihim ito.

Unang Hakbang Setup ng App at Spare Key

Paano I-install ang Mobile App

Maaari mong i-install ang iReside sa iyong cellphone para sa mabilisang access:

Android Pag-install sa Android Phone
  1. Buksan ang kaliwang menu at pindutin ang Download App.
  2. Pindutin ang Download iReside App upang i-save ang APK.
  3. Buksan ang na-download na file at pindutin ang Install.
  4. Kapag nagtanong ang Android security, piliin ang Allow.
iPhone Pagdagdag sa iPhone Home Screen
  1. Buksan ang Safari browser at pumunta sa iReside portal.
  2. Pindutin ang Share button sa ibaba ng screen.
  3. Mag-scroll pababa at pindutin ang Add to Home Screen.
  4. Pindutin ang Add sa kanang itaas upang matapos.

Kakayahan ng Cellphone at mga Kinakailangan

Uri ng Platform Pinakamababang Sistema Mga Sinusuportahang Gamit
Android Client Android 8.0 (Oreo) o mas bago Native APK, notification alerts, at camera uploads.
Apple iOS iOS 14.0 o mas bago Safari Home Screen PWA at camera uploads.
Desktop Browser Chrome, Firefox, Safari, Edge Keyboard navigation, dual monitors, at reports.

Ang Emergency Spare Key (Pagbawi ng Account)

Tulad ng ekstrang susi sa bahay, magagamit ito kapag nawala ang cellphone.

Mga Detalye ng Emergency Spare Key

Katangian ng Susi Pamantayang Teknikal Tuntunin sa Pag-iingat
Anyo ng Code 16 na malalaking titik at numero Nahahati sa apat na pangkat na may gitling.
Paraan ng Pag-save One-way bcrypt cryptographic hash Hindi nakatago online ang tunay na teksto.
Limitasyon sa Gamit Isang beses lamang magagamit Awtomatikong pinapalitan pagkatapos mag-login.
Itago ang iyong Emergency Spare Key sa flash drive o isulat sa ligtas na papel.

Gabay ng Umuupa Kontrata at Buwanang Bayarin
Task T1 Lumagda sa Digital na Kontrata (Sign Lease)

Bago lumipat sa kuwarto, kailangang pirmahan ng umuupa ang kontrata:

  1. Pindutin ang Leases sa kaliwang menu.
  2. Pindutin ang Review & sign button sa itaas ng screen.
  3. Basahin nang maigi ang buwanang upa, deposito, at mga patakaran.
  4. Pindutin ang Sign Document upang buksan ang signature pad.
  5. Guhit ang iyong lagda gamit ang daliri o mouse.
  6. Pindutin ang Finalize at kumpirmahin upang maipasa ang kontrata.
Task T2 Tingnan ang Buwanang Upa at Bayarin

Alamin ang iyong bayarin sa upa, submeter, at nakaraang bayad:

  1. Pindutin ang Finance Hub sa navigation menu.
  2. Tingnan ang balanse sa ilalim ng Total Balance Due.
  3. Tingnan ang konsumo sa tubig at kuryente sa submeter.
  4. Alamin ang petsa ng bayad upang maiwasan ang multa.
  5. Pindutin ang View Statement upang makita ang singil.

Mga Tuntunin sa Kontrata at Singil sa Upa

Uri ng Bayarin Tuntunin ng Patakaran Tungkulin ng Umuupa
Buwanang Upa Dapat bayaran sa unang araw ng buwan. Magsumite agad ng resibo ng bayad.
Security Deposit Garantiya sa sira at naiwang singil. Ibabalik sa loob ng 15 araw paglipat.
Unpaid / Overdue Singil na dapat nang bayaran ngayon. Bayaran agad upang walang abala o multa.
Paid / Pending Bayad na o sinusuri pa ng may-ari. I-download at itago ang digital na resibo.

Pamantayan sa Pangungupahan at Batas

Batas / Alituntunin Itinatakda ng Batas Patakaran sa Sistema
Rent Control Act Limitasyon sa taunang pagtaas ng upa. Sinusunod ang limitasyon sa presyo.
Security Deposit Hanggang dalawang buwang deposito lamang. Nililimitahan ang halaga sa pag-set up.
Grace Period Karaniwang 5 araw na palugit sa bayad. Ipinapataw ang multa pagkatapos ng palugit.

Gabay ng Umuupa Bayad sa Upa at mga Resibo
Task T3 Magbayad ng Upa Gamit ang GCash o Maya

Maaari kang magbayad ng upa gamit ang cellphone nang hindi lumalabas ng bahay:

  1. Buksan ang Finance Hub at pindutin ang Upload Payment.
  2. I-scan ang GCash QR code o kopyahin ang mobile number ng may-ari.
  3. Tapusin ang bayad sa GCash at kumuha ng screenshot ng resibo.
  4. Bumalik sa iReside at i-upload ang screenshot ng resibo.
  5. I-type ang eksaktong Reference Number mula sa resibo.
  6. Pindutin ang Submit Payment upang maipasa sa may-ari.
Yugto ng Pagbabayad Responsableng Tao Dokumentong Katibayan
1. Pagpasa ng Bayad Umuupang Residente Mag-upload ng resibo na may reference number.
2. Pagsusuri Accounting Ledger Ilalagay ang bayad sa pending review ledger.
3. Pag-apruba May-ari ng Paupahan Kukumpirmahin ang bayad at maglalabas ng resibo.
4. Resibo Sistema ng iReside Awtomatikong magbibigay ng opisyal na electronic resibo.
Paalala sa Bayad: Tiyaking tama ang 13-digit GCash reference number bago isumite.
Task T4 Magbayad ng Cash sa May-ari

Kung nais mong magbayad ng pisikal na pera nang direkta sa may-ari:

  1. Pumunta sa opisina ng may-ari at iabot ang eksaktong halaga.
  2. Hintaying maitala ng may-ari ang bayad sa iReside portal.
  3. Buksan ang Finance Hub screen at i-refresh ang pahina.
  4. Tingnan ang bagong resibo sa ilalim ng Payment History.

Paghahambing ng Paraan ng Pagbabayad

Paraan ng Bayad Kailangang Patunay Oras ng Pag-apruba
GCash / Maya Transfer Screenshot at 13-digit reference number Maaaprubahan sa loob ng 24 oras.
Cash sa May-ari Direktang iabot sa opisina ng pamunuan Agad na maia-update sa electronic ledger.

Gabay ng Umuupa Pag-ulat ng Sira at Mensahe
Task T5 Magsumite ng Tiket sa Pagkumpuni (Report Repairs)

Kung may sirang gripo, problema sa kuryente, o iba pang sira sa kuwarto:

  1. Pindutin ang Maintenance sa kaliwang menu.
  2. Pindutin ang + Submit Request button sa kanang itaas.
  3. Pumili ng kategorya at i-type ang paliwanag ng sira.
  4. Pindutin ang Upload Photo at pumili ng litrato.
  5. Pindutin ang Submit Ticket upang maipadala ang kahilingan.
Yugto ng Pagkumpuni Responsableng Tao Pamantayan sa Aksyon
1. Pagsumite ng Tiket Umuupang Residente Maglagay ng malinaw na paliwanag at litrato.
2. Pagtakda ng Gawain May-ari ng Paupahan Titingnan ang sira at magtatalaga ng tagakumpuni.
3. Pagkumpuni Itinalagang Tagakumpuni Aayusin ang sira at titingnan kung maayos.
Paalala sa Sira: Kumuha ng malinaw na litrato upang mabilis maaksyunan ang pagkumpuni.
Task T6 Magpadala ng Direktang Mensahe sa May-ari

Para sa mga katanungan, paunawa, o pag-uusap kasama ang pamunuan:

  1. Pindutin ang Messages sa kaliwang navigation sidebar.
  2. Piliin ang pag-uusap kasama ang iyong property manager.
  3. I-type ang iyong mensahe o tanong sa message composer box.
  4. Pindutin ang Send icon upang maipadala agad ang mensahe.
  5. Makatatanggap ka ng abiso kapag sumagot ang may-ari.

Priyoridad sa Pagkumpuni at Oras

Kategorya ng Sira Halimbawa ng Problema Target na Oras ng Pag-ayos
Plumbing Tagas sa tubo, sirang gripo, baradong lababo Maaayos sa loob ng 24 oras.
Electrical Bukas na kable, pumutok na breaker, ilaw Aayusin agad o sa loob ng 12 oras.
Kandado at Pinto Sira sa seradura, sirang bintana, bisagra Maaayos sa loob ng 48 hanggang 72 oras.

Gabay ng Umuupa Paglipat at Pagbawi ng Account
Task T7 Magpasa ng Paunawa sa Paglipat (Notice to Vacate)

Kung matatapos na ang kontrata at balak mo nang umalis sa kuwarto:

  1. Pindutin ang Leases sa pangunahing navigation menu.
  2. Tingnan ang mga detalye ng iyong kasalukuyang kontrata.
  3. Pindutin ang Submit Move-Out Notice button.
  4. Piliin ang petsa ng iyong pag-alis gamit ang kalendaryo sa screen.
  5. Ilagay ang dahilan ng pag-alis at pindutin ang Confirm Notice.
Task T8 Mag-sign In Gamit ang Emergency Spare Key

Kung nawala ang iyong cellphone o hindi mabuksan ang email inbox:

  1. Sa login screen, pindutin ang link na Use Emergency Key.
  2. I-type ang iyong rehistradong email address sa account.
  3. I-type ang iyong 16-character Emergency Spare Key code.
  4. Pindutin ang Unlock Account button upang makapasok.
  5. Gumawa ng bagong password at i-save ang bagong susi na ibibigay.

Talaan sa Pag-alis at Pagbawi ng Susi

Bahagi ng Gawain Kinakailangang Aksyon Pamantayan sa Pagsang-ayon
Kalinisan ng Kuwarto Naitapon ang basura at malinis ang sahig. Sisingilin ang cleaning fee kung marumi.
Pagsasauli ng Susi Naibalik ang lahat ng susi sa gate at pinto. Ibabawas sa deposito ang nawawalang susi.
Huling Metro Nakuha ang huling basa ng tubig at kuryente. Ibabawas sa deposito ang huling singil.
Pagbawi ng Account Ilagay ang 16-character emergency code. Papalitan ang password at magbibigay ng susi.

Iskedyul ng Pagbawas at Pagbalik ng Deposito

Aytem ng Bawas Pamantayan sa Pagsusuri Oras ng Pag-aayos
Mga Balanseng Bill Huling metro ng kuryente at tubig. Ibinabawas sa natitirang deposito.
Sira sa Kuwarto Pagsusuri at halaga ng pagkumpuni. May resibo ng mga materyales.
Natitirang Pera Deposito bawas ang mga bayarin. Ibinabalik sa loob ng 15 araw.
Paalala sa Seguridad: Itago ang iyong Emergency Spare Key offline. Huwag itong ipadala sa chat.

Gabay ng May-ari Gusali at Mapa ng Kuwarto
Task L1 Magdagdag ng Bagong Gusali at mga Kuwarto

Irehistro ang bagong paupahang gusali at ang mga kuwarto nito sa portal:

  1. Pindutin ang Properties sa kaliwang navigation sidebar.
  2. Pindutin ang Add Property button sa itaas na action bar.
  3. Ilagay ang pangalan ng gusali sa ilalim ng Property Name.
  4. Ilagay ang buong address at piliin ang bilang ng mga palapag.
  5. Tukuyin ang bilang ng mga kuwarto para sa bawat palapag.
  6. Pindutin ang Create Property upang mai-save ang gusali sa iReside.
Preset ng Gusali Ayos ng Pasilyo Uri ng Paupahan
Double Loaded Gitnang pasilyo na may mga kuwarto sa magkabilang gilid. Mga apartment at boarding house na may palapag.
Single Loaded Isahang pasilyo na may bukas na rehas o balkonahe. Mga row house at paupahang may bukas na daanan.
U-Shape Layout Tatlong panig na gusali na nakapalibot sa bakuran. Mga compound at gated residential rental properties.
Pamantayan sa Mapa: I-drag ang room cards sa grid upang tumugma sa pasilyo.
Task L2 I-ayos ang Interactive Unit Map ng Gusali

Gumawa ng visual na 2D floorplan upang madaling makita ang bawat pasilyo:

  1. Pindutin ang Unit Map sa pangunahing navigation menu.
  2. Pumili ng architectural preset tulad ng Double Loaded o Single Loaded.
  3. I-drag at i-drop ang mga room card upang tumugma sa totoong pasilyo.
  4. Pindutin ang alinmang kuwarto upang i-edit ang numero at buwanang upa.
  5. Pindutin ang Save Layout upang mai-publish ang plano ng palapag.

Mga Katangian ng Gusali at mga Limitasyon

Field ng Detalye Limitasyon sa Input Gabay sa Operasyon
Pangalan ng Gusali Hanggang 60 titik at numero Gamitin ang opisyal na pangalan ng gusali.
Tirahan / Address Lokasyon sa Barangay Marulas Dapat nasa loob ng saklaw ng Marulas pilot.
Bilang ng Palapag Mula 1 hanggang 10 palapag Bubuo ng mga lebel sa mapa ng gusali.

Gabay ng May-ari Singil sa Utility at Umuupa
Task L3 I-configure ang Singil sa Tubig at Kuryente

Itakda ang presyo ng kuryente at tubig bago magkalkula ng submeter:

  1. Pindutin ang Utility Billing sa kaliwang menu.
  2. Buksan ang tab ng Electricity & Water Rates.
  3. Ilagay ang presyo ng kuryente kada kWh at tubig kada metro kubiko.
  4. Ilagay ang iyong opisyal na GCash Mobile Number at pangalan.
  5. Pindutin ang Save Financial Configuration upang mailapat sa mga kuwarto.
Tip: Tiyaking tama ang iyong GCash name upang hindi malito ang mga umuupa sa pagbayad.
Task L4 Magdagdag ng Bagong Umuupa (Quick Add)

Ang pinakamabilis na paraan ng pagrehistro kapag kaharap ang umuupa:

  1. Pindutin ang Tenants sa sidebar at i-click ang + Add Tenant.
  2. Piliin ang tab na Quick Add sa window.
  3. Ilagay ang Buong Pangalan, Email Address, at Cellphone Number.
  4. Pumili ng bakanteng kuwarto, buwanang upa, at petsa ng pagsisimula.
  5. Pindutin ang Create Tenant Account upang mabuo ang kredensyal.

Istraktura ng Singil sa Tubig at Kuryente

Serbisyo ng Utility Yunit ng Sukat Pormula sa Pagsingil
Kuryente Kilowatt-hour (kWh) Konsumo na imumultiplika sa presyo ng kWh.
Tubig Metro Kubiko (m³) Konsumo na imumultiplika sa presyo ng metro.
GCash Account 11-digit mobile number Ipinapakita sa buwanang invoice ng umuupa.

Mga Paraan ng Pagdagdag ng Umuupa

Paraan ng Pagdagdag Inaasahang Umuupa Mabubuong Resulta

Gabay ng May-ari Invites at mga Aplikante

Pahintulutan ang mga aplikante na sagutan ang form gamit ang cellphone:

  1. Sa loob ng Add Tenant window, piliin ang Self-Onboarding Link.
  2. Piliin ang bakanteng kuwarto at kung kailan mapapaso ang link.
  3. Pindutin ang Generate Onboarding Link upang mabuo ang URL.

Paraan ng Pagdagdag Pamamaraan sa Paggawa Pangunahing Pakinabang

Gabay ng May-ari Bayad at Submeter
Task L7 Kumpirmahin at Tanggapin ang Bayad sa Upa

Kumpirmahin ang bayad gamit ang GCash transfer o pisikal na cash:

  1. Pindutin ang Finance Hub sa kaliwang navigation sidebar.
  2. Sa ilalim ng Pending Verification, pindutin ang bayad ng umuupa.
  3. Suriin ang screenshot ng resibo at itugma ang reference number.
  4. Pindutin ang Confirm Payment button upang aprubahan ang bayad.
  5. Agad na maia-update ang balanse at maglalabas ng opisyal na resibo.
Task L8 Magtala ng Basa sa Submeter (Kuryente at Tubig)

Awtomatikong kalkulahin ang bayarin sa tubig at kuryente ng bawat kuwarto:

  1. Pindutin ang Utility Billing at buksan ang Submeters tab.
  2. Pumili ng kuwarto at ilagay ang bagong numero sa Current Reading.
  3. Awtomatikong kukuwentahin ng sistema ang nakonsumong yunit mula sa lumang basa.
  4. Kakalkulahin ang kabuuang halaga gamit ang itinakdang presyo sa sistema.
  5. Pindutin ang Save Reading upang maitala ang singil.

Pamantayan sa Bayad at Submeter ng Utility

Uri ng Aksyon Pamantayan sa Pagsusuri Resulta sa Ledger
GCash / Maya Itugma ang 13-digit reference number sa resibo. Mamarkahang bayad at gagawa ng resibo.
Pisikal na Cash Kumpirmahin ang eksaktong perang natanggap. Itala ang transaksyon sa electronic ledger.
Kulang na Bayad Mas mababa ang ibinayad kaysa sa singil. Ibabawas ang bayad; maiiwan ang balanse.
Basa sa Submeter Kunin ang konsumo mula sa dating basa. Imumultiplika sa presyo ang konsumo.

Pamantayan sa Singil ng Tubig at Kuryente

Uri ng Utility Paraan ng Pagkuwenta Pamamaraan ng Pagsusuri

Tubig (Cubic Meter) Nagamit na tubig na pinarami sa presyo. Inihahambing sa opisyal na bill.

Gabay ng May-ari Pagkumpuni at mga Anunsyo
Task L9 Mamahala at Mag-ayos ng Tiket ng Pagkumpuni

Iproseso ang mga ulat ng sira na ipinasa ng mga umuupang residente:

  1. Pindutin ang Maintenance sa kaliwang navigation sidebar.
  2. Pindutin ang alinmang tiket na may pulang marka o Pending status.
  3. Suriin ang paliwanag ng sira at ang litratong ipinasa ng umuupa.
  4. Piliin ang tagakumpuni: Landlord Repair o Third Party Repair.
  5. Pindutin ang To Process button upang simulan ang iskedyul.
  6. Kapag tapos na ang gawa, pindutin ang Mark as Completed button.
Uri ng Paunawa Saklaw ng Anunsyo Antas ng Priyoridad
Abiso sa Utility Nakatakdang pagkawala ng tubig o kuryente. Mataas na priority banner sa dashboard.
Paalala sa Bayad Paparating na takdang petsa ng upa. Karaniwang paalala sa notification feed.
Tuntunin sa Gusali Oras ng katahimikan at tapunan ng basura. Paskil sa community bulletin board.
Pamantayan sa Anunsyo: Makikita agad ang mga anunsyo sa mobile dashboard ng mga umuupa.
Task L10 Magpaskil ng mga Anunsyo sa Gusali

Maghatid ng mahahalagang abiso sa mga residente (tulad ng maintenance sa tubig):

  1. Pindutin ang Community Hub sa kaliwang navigation sidebar.
  2. Sa composer toolbar, pindutin ang tab na Announcement.
  3. I-type ang buong detalye ng paunawa para sa mga umuupa sa gusali.
  4. Pindutin ang Photo kung nais mong magsama ng litrato o poster.
  5. Pindutin ang Publish button sa kanang ibabang bahagi.

Access Control Strict Two-Role Human User Model

Strict Two-Role Human User Model

Per system rules, iReside implements a strict two-role model with zero admin role:

  • Landlord: Property owner. Manages properties, unit maps, leases, invoices, and maintenance.
  • Tenant: Resident occupant. Signs digital leases, submits payments, logs maintenance tickets.

Service Role Operational Model

Automated processes that require cross-tenant or system-level access use secure service role tokens:

  • Automated Billing Cron: Daily midnight worker generates recurring rent and overdue charges.
  • Workspace Initialization (/api/setup/launch): Bypasses client RLS to stamp initial configuration.
  • Disaster Recovery & Seeding: Dedicated CLI maintenance scripts run via service role key.

Authentication 2FA Engine & Session Guards

Two-Factor Authentication (2FA) Lifecycle

iReside implements mandatory email-delivered 6-digit OTP verification for secure sessions:

  1. User submits credentials at /login via Supabase Auth PKCE flow.
  2. Server generates an ephemeral 6-digit cryptographic token (10-minute expiry).
  3. Token is dispatched via transactional SMTP to the verified email.
  4. User inputs token; upon verification, Supabase issues signed JWT and refresh tokens.

Authentication Threat Model & Defense Mechanisms

Threat Vector Risk Level Defense Architecture
Brute Force Login High Rate limit: 5 failed attempts per IP.
Session Hijacking Critical HTTP-only SameSite cookies and TLS 1.3.
OTP Replay Attack Medium 10-minute expiry on single-use OTP codes.
Client Lock Stalls High Background non-blocking auth refresh execution.

The Emergency Spare Key Architecture

The Emergency Spare Key provides failsafe account recovery when losing phone or email access:

Parameter Cryptographic Standard Operational Implementation

Account Recovery Verification Protocol

Recovery Step Verification Check Expected System Response
